# VPN013 WG — подпись и проверка на iPhone

Это отдельная изменённая сборка AmneziaWG из официальных исходников, а не официальный
релиз Amnezia. Исходный MIT copyright сохранён. IPA без действительной подписи Apple,
с технической ad-hoc подписью для целостности и сохранения объявленных прав. Перед
установкой его нужно переподписать вашим сертификатом и профилями; личных VPN-ключей внутри нет.

Для ESign нужны действующий сертификат и профили, допускающие:

- приложение `com.vpn013.awg`;
- расширение `com.vpn013.awg.network-extension`;
- для обоих `com.apple.developer.networking.networkextension = [packet-tunnel-provider]`.

Профили должны быть выданы вашей команде Apple и разрешать нужные идентификаторы,
устройство и способ установки. Одной возможности подписать обычное приложение
недостаточно. ESign не может создать отсутствующие в профиле права Apple.
Не удаляйте `PlugIns/WireGuardNetworkExtension.appex`. Подпишите вложенное расширение
и приложение одной командой; сохраните указанные права. Если меняете Bundle ID,
нужно согласованно изменить ID расширения и разрешённые идентификаторы подписи.
Сохранить исходные ID проще.
Названия пунктов ESign зависят от версии, поэтому неподтверждённый путь по меню не указан.

Сборка 1.1.0 не требует App Group или общего Keychain. Конфигурации в системном
VPN-профиле зашифрованы AES-256-GCM; ключ хранится отдельно в личном контейнере
каждого процесса с защитой файлов iOS и исключением из резервного копирования.
При первом включении из приложения ключ передаётся расширению через штатные
параметры запуска VPN. В дальнейшем расширение использует собственную копию.
После перезагрузки телефона требуется первое разблокирование. Нельзя подставлять
чужую App Group из сертификата: приложение не использует её даже при наличии.
Совместимость конкретной подписи ESign подтверждается только физическим тестом.

После установки:

1. Импортируйте свои конфигурации AmneziaWG/WireGuard из ZIP или отдельных файлов.
2. Выключите VPN. Нажмите «+ → Создать режим Авто», проверьте количество и список, «Создать Авто».
3. Первый раз включите «Авто» именно из VPN013 WG и разрешите VPN в iOS.
4. В карточке Авто отображается текущий сервер и результат проверки трафика.

Автоматика использует копии прежних ключей из этого архива. Если исходные файлы
поменялись, пересоздайте Авто. Продление прежних серверных ключей не требует новых файлов.
Обычный экспорт `.conf` не переносит автоматическую группу: на другом устройстве
импортируйте исходные профили и создайте Авто заново. Поддерживаются сторонние
серверы; жёсткого списка стран нет. Нужен один peer с endpoint и полным IPv4-туннелем.
При единственном сервере переключаться некуда — это показано до создания.
Проверки выполняются внутри VPN-расширения через HTTPS Apple/Cloudflare с системной
проверкой сертификатов. Они раскрывают этим сервисам IP выхода VPN, не ключи или ID.
После двух неудачных проверок выбирается следующий сервер. При отсутствии сети
перебор приостанавливается; после неудачи всех серверов — пауза минута. Ручное выключение
останавливает автоматику. Постоянная готовность всех серверов не гарантируется.
Это не обещание отсутствия утечек: обычные ограничения VPN iOS сохраняются; существующие
TCP-соединения при смене IP могут оборваться. Полноценный Kill Switch отдельно не заявлен.

Нужна проверка на физическом iPhone: импорт, трафик, отказ первого сервера,
переключение на резерв, блокировка экрана, переход Wi-Fi/LTE и ручное выключение.
Симулятор не подтверждает реальную работу VPN.
